## Summary

This is the index for SOPs for various tasks handling the BCLConvert InterOp QC Pipeline
for a given instrument run.

These tasks range from:
* Installation / deployment of a new CWL Workflow onto the ICAv2 platform
* Verifying a new version of the BCLConvert InterOp QC Pipeline
* Troubleshooting common issues with the BCLConvert InterOp QC Pipeline
* Kicking off a reanalysis of a set of samples manually
